# Milestone Prompt Template

Copy this prompt and replace the milestone number:

```text
Read CLAUDE.md, docs/architecture.md, docs/roadmap.md, and the selected
milestone brief.

Inspect the current implementation and git status.

Before coding:
1. Summarise the current state.
2. Propose a focused implementation plan.
3. List files likely to change.
4. Identify package, platform, and architecture risks.
5. Ask questions only if a decision is genuinely blocking.

After approval:
- Implement only the selected milestone.
- Keep changes focused.
- Add/update tests.
- Build and run tests; do not report success without actual results.
- Update documentation.
- Summarise changes, verification, limitations, and next step.
- Do not start the next milestone.
```
